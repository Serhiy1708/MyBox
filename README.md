# MyBox# Моя коробка

Особистий PWA-додаток з модулями: комуналка, кредити, календар.

## Що це

Одна коробка (оболонка), в яку вкладаються модулі. Кожен модуль — окремий
файл у `modules/<id>.js`, який експортує об'єкт з методами:

- `init(container)` — малює і запускає модуль
- `getData()` — повертає дані для пакетного експорту
- `setData(data)` — приймає дані при імпорті
- `resetData()` — очищає дані

## Файли

| Файл | Що робить |
|---|---|
| `index.html` | Каркас (2 екрани: дашборд + модуль) |
| `style.css` | Тема (темна, фіолетовий акцент) |
| `app.js` | Логіка коробки, реєстр модулів, експорт/імпорт |
| `manifest.json` | PWA-конфіг |
| `sw.js` | Service Worker (офлайн) |
| `modules/_template.js` | Шаблон для нових модулів |

## Як додати новий модуль

1. Скопіюй `modules/_template.js` → `modules/<id>.js`.
2. Заповни `styles`, `template`, `init`, `getData`, `setData`.
3. У `app.js` у масиві `modules` додай рядок:
